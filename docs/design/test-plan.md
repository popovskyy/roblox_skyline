# SkylineZero — план тестування

> **Status (17.10, build b24):** Written against Cursor's experimental builds. The steps still apply; ignore references to 240-stud floors, `src_lobby/` and rbxlx injection. Current checks per build live in `CHANGELOG.md`.
>
> Imported from the Cursor team's notes. Where this doc and the code disagree, the code and `GameConfig` win.


Північна зірка: гра затягує і не бісить. Перші хвилини самі ведуть гравця. Фікси беклогу — строго по порядку; після кожного фіксу проганяти відповідний блок регресії + «запахи» з кінця документа.

**Це не м’який QA-чекліст.** Мета — ламати first-session fun. Знайшов «прогалину» → пиши в [gap-report.md](./gap-report.md) з severity + repro. Не закривай кейс, бо «ніби працює».

**Places (у Context store):** `artifacts/places/SkylineZero.rbxlx` (main), `artifacts/places/SkylineZero_Lobby.rbxlx` (Lobby). На VM кодера можуть лежати як `places/…`.

**Як користуватись:** чекбокс = один прогін. Ставити `[x]` лише коли критерій пройдено на цільовій платформі. Для кооп-кейсів — мінімум 2 клієнти.

## 1. First 5 minutes — ясність без Discord

Мета: новий гравець за ~5 хв розуміє **що збирати, куди йти, навіщо**, без зовнішніх підказок.

### 0:00–0:30 — вхід / лобі

- [ ] Після джойна видно, що це кооперативний пост-апок / зомбі-ран (не порожній хаб без сенсу)
- [ ] Є очевидний наступний крок у лобі (ліфт / черга / «почати»), без читання чату
- [ ] Старі вивіски «1 соло / 2 / 4 / 6» відсутні або не конкурують з актуальним UI
- [ ] Діалог вибору гравців 2–6 з’являється в потрібний момент; макс. 6; невалідні значення відхиляються
- [ ] Соло / порожня команда: гравець розуміє, чи може стартувати і що чекає в матчі

### 0:30–2:00 — дах → спуск → лут (UX: ~180s loop)

- [ ] 0–20s: ціль = термінал; маркер на Emergency Terminal (не «порожній дах»)
- [ ] Після терміналу: одна нова ціль + маркер на сходи (`СХОДИ ВНИЗ ↓`)
- [ ] На тех. поверсі: HUD показує **live** `Металобрухт n/3` (не статичний текст без числа)
- [ ] Найближчий scrap має glow / outline / очевидний prompt `Зібрати`
- [ ] Маркер на кроці луту **не** лишається на сходах, поки scrap не зібрано (або явно веде до scrap)
- [ ] Немає глухого кута: усі видимі інтерактиви або працюють, або пояснюють чому ні
- [ ] Підказки: max 1 toast / 15s; немає second modal mid-loot
- [ ] Керування зрозуміле на платформі тесту (PC / touch / геймпад) без Discord

### 2:00–5:00 — перший цикл «зробив → нагорода → наступне»

- [ ] Повний мікроцикл UX: loot 3 scrap → return roof → (chest/build hint) без Discord
- [ ] Кожен пікап миттєво тикає `1/3` → `2/3` → `3/3` на HUD
- [ ] На 3/3: ціль пульсує → return marker на дах
- [ ] Зрозуміло, звідки хіл (крафт / лут) до першої downed-смерті команди
- [ ] Смерть / downed не ламає розуміння цілі (маркер тіммейта або наступний крок)
- [ ] Після 5 хв гравець каже вголос: «я збираю ___, щоб ___» — без підказок тестера

### Fail критерій першої сесії (блокує реліз онбордингу)

- [ ] FAIL якщо >50% тестових новачків за 2 хв питають «що робити?»
- [ ] FAIL якщо єдиний шлях прогресу — знання з Discord / стрімів
- [ ] FAIL якщо перший інтерактив дає хибне блокуюче повідомлення (напр. електроніка = «завал»)
- [ ] FAIL якщо за ~180s новачок не завершив loot→return (див. `first-session-ux.md`)
- [ ] FAIL якщо маркер веде не туди, куди каже ціль (сходи замість scrap / electronics)

## 2. Регресія по беклогу (суворо по порядку)

Після кожного фіксу: цей блок + §1 (якщо фікс торкається старту) + §4 «запахи».

### 2.1 Ліфти та вибір гравців

**Прибрати старі дефолтні вивіски («1 соло», «2», «4», «6»)**

- [ ] У Lobby немає старих вивісок / Part з текстом 1/2/4/6 як вибір розміру партії
- [ ] У main place немає застарілих підписів, що суперечать новому діалогу
- [ ] Камера / UI не лишає «дірки» після видалення (немає плаваючих порожніх білбордів)

**Діалог при вході в ліфт: вибір кількості гравців 2–6 (макс. 6)**

- [ ] Вхід у ліфт відкриває діалог вибору 2–6
- [ ] Немає опції >6 і немає «1 соло» якщо продукт це прибрав
- [ ] Вибір застосовується до матчу / черги; повторний вхід не ламає стан
- [ ] Скасування / вихід з діалогу не телепортує в зламаний стан
- [ ] Кооп: усі клієнти бачать узгоджену кількість слотів
- [ ] Edge: швидкий повторний тригер ліфта не дублює діалоги

### 2.2 Завали та лутання

**Розбирання завалів — деякі зараз неможливо розібрати**

- [ ] Кожен тип завалу на тестових поверхах можна розібрати валідним інструментом / дією
- [ ] Прогрес розбирання видимий; після завершення шлях відкривається
- [ ] Немає «вічних» завалів з 0 прогресу при правильній взаємодії
- [ ] Завал не блокує сусідні валідні лут-промпти помилково

**Підбір електроніки — блокується помилковим повідомленням про завал**

- [ ] Підбір електроніки з підлоги / контейнера успішний без повідомлення про завал
- [ ] Повідомлення про завал з’являється **лише** біля реального завалу
- [ ] Немає хибного overlap prompt / touch zone між електронікою і завалом
- [ ] Після фіксу: інвентар отримує айтем; лічильник луту (якщо релевантний) +1

**Дроп айтемів з інвентарю на землю (тіммейти можуть підібрати)**

- [ ] Дроп з інвентарю створює світовий пікап
- [ ] Той самий гравець може підібрати назад
- [ ] Тіммейт може підібрати дроп
- [ ] Не-тіммейт / інша команда: поведінка за правилами гри (задокументувати факт)
- [ ] Дроп під час смерті / респауну не дублює і не губить предмети безслідно
- [ ] Мобільний UI: дроп доступний і не випадковий (не місклік замість use)

**Спільна скриня команди — спільний вміст замість персональної скрині**

- [ ] Гравці однієї команди бачать однаковий вміст скрині
- [ ] Покласти айтем з A → видно в B без релоаду place
- [ ] Забрати айтем з B → зникає у A
- [ ] Дві одночасні операції не дублюють / не їдять айтеми (race)
- [ ] Після респауну / реджойну тіммейта спільний стан зберігається в межах сесії
- [ ] Персональна скриня більше не використовується як основна (або чітко відділена в UI)

### 2.3 Трекінг квестів / HUD

**Лічильник прогресу луту оновлюється в реальному часі (напр. `2/4`, не застряглий `0/3`)**

- [ ] Старт квесту показує коректний `0/N` (N збігається з ціллю)
- [ ] Кожен валідний пікап миттєво оновлює чисельник на всіх клієнтах команди
- [ ] Немає залипання на `0/3` після реального луту
- [ ] Завершення `N/N` тригерить наступний крок / маркер / повідомлення
- [ ] Смерть / респаун не скидає прогрес помилково (якщо дизайн цього не вимагає)
- [ ] Реджойн mid-run: лічильник синхронізується з сервером

**Маркер смерті тіммейта: напрямок + відстань для живих членів команди**

- [ ] Після смерті тіммейта живі бачать маркер / індикатор
- [ ] Є напрямок (стрілка / world marker) і відстань (м або еквівалент)
- [ ] Маркер зникає після респауну / підйому / кінця раунду (за правилами)
- [ ] Немає маркера на ворогів / NPC як «тіммейт»
- [ ] На мобайлі маркер читабельний і не перекриває критичний touch UI

### 2.4 Спавн ворогів

**Прибрати респаун зомбі на поверсі після зачистки (усі поверхи, включно з першим)**

- [ ] Поверх 1: після повної зачистки зомбі не респауняться на цьому поверсі
- [ ] Середні поверхи: те саме
- [ ] Верхні / фінальні тестові поверхи: те саме
- [ ] Нові хвилі / інші поверхи все ще спавнять за дизайном (не зламали глобальний спавн)
- [ ] AFK 2–3 хв на зачищеному поверсі — вороги не «тихо» повертаються
- [ ] Реджойн тіммейта на зачищений поверх не респаунить хвилю

### 2.5 Атмосфера, візуал, освітлення

**Освітлення поверхів: прибрати сильне мерехтіння при вході; трохи темніше**

- [ ] Вхід на поверх: немає різкого strobe / flicker світла
- [ ] Загальна освітленість трохи темніша, але геймплейні цілі (лут, двері, вороги) читабельні
- [ ] Немає епілептичних спалахів при дверях / ліфті / респауні
- [ ] Перевірка на low graphics + high graphics

**Дах / далекий план: прибрати «ботанічний сад»; похмурий пост-апок (TLOU-вайб)**

- [ ] Дах / skyline не виглядає як яскравий ботанічний сад
- [ ] Домінують похмурі, зруйновані, «мертві» силуети
- [ ] Немає випадкових яскравих зелених «паркових» плям, що ламають тон
- [ ] Скріншот reference-check: «це той самий тон, що маркетинг обіцяє»

**Скайбокс / хмарочоси: при погляді вниз не мають «літати в повітрі»**

- [ ] З даху / високого вікна вниз: хмарочоси мають візуальну опору / коректний горизонт
- [ ] Немає «літаючих» веж у повітрі при pitch down
- [ ] Камера 1-ї / 3-ї особи: артефакт не повертається
- [ ] Різні FOV / graphics levels — той самий результат

**Динамічна погода (дощ) і зміна часу доби (день / ніч)**

- [ ] Дощ запускається / зупиняється без крашу і без перманентного «мокрого» глітчу
- [ ] Перехід день → ніч помітний і атмосферний, не ламає видимість критичних промптів
- [ ] Звук / VFX дощу не спамить FPS нижче прийнятного на mid device
- [ ] Ніч: маркери квесту / смерті тіммейта все ще читабельні
- [ ] Погода синхронна між клієнтами однієї сесії (або різниця не помітна як баг)

### 2.6 Геймплей і баланс

**Онбординг: зрозуміла черговість дій на старті**

- [ ] Є впорядкована послідовність кроків (1 → 2 → 3), не паралельний хаос без пріоритету
- [ ] Кожен крок розблоковує або пояснює наступний
- [ ] Повторний запуск для нового акаунта дає той самий зрозумілий шлях
- [ ] Пройти §1 First 5 minutes повністю після цього фіксу

**Баланс аптечок / хілок: звідки брати нові, крафт**

- [ ] Гравець розуміє джерела хілу (лут / крафт / вендор / скриня) без Discord
- [ ] Крафт (якщо є): рецепт видимий; інгредієнти знаходяться в розумному радіусі раннього геймплею
- [ ] Після повного витрати аптечок є шлях отримати нові до «мертвої» стіни
- [ ] Хіл не відчувається ні безкоштовним спамом, ні повним голодом у перші 10 хв
- [ ] Кооп: один гравець не може lock-out усю команду від хілу через персональну скриню (див. спільну скриню)

**Економіка жетонів: менше видачі, більше цінності**

- [ ] За стандартний 10–15 хв ран токени не сиплються «як конфеті»
- [ ] Покупки / апгрейди відчуваються як рішення, не як сміття
- [ ] Немає очевидного infinite farm за 1 хв (двері / респаун / AFK)
- [ ] UI балансу / вартості читабельний; ціни не суперечать новій видачі
- [ ] Порівняти before/after: середній earn/час знизився АБО sinks стали сильнішими (зафіксувати числа в нотатках прогону)

### 2.7 Крос-платформа (беклог-айтем)

**Анімації ударів видно на мобайлі й планшеті (зараз лише на PS5)**

- [ ] PC: melee swing / hit anim видимі локально і на іншому клієнті
- [ ] PS5 / console: як і раніше видимі
- [ ] Mobile (телефон): ударна анімація видима локально
- [ ] Mobile: ударна анімація видима іншим гравцям, що дивляться на атакуючого
- [ ] Tablet: те саме, що mobile
- [ ] Немає «тихих» ударів без VFX/anim при реальному хіті
- [ ] Hitbox і anim синхронні достатньо, щоб не виглядати як чит / лаг-фейк

- [ ] Анімація відтворюється при кожному swing (не лише при hit confirm)

## 4. «Annoying» smells — ебейша перевірка

Проганяти після кожного великого фіксу і перед будь-яким «готово до плейтесту».

### Неясні цілі

- [ ] Немає екрана >10 с без видимої цілі / маркера / наступного кроку
- [ ] Текст HUD = дієслово + об’єкт («Збери електроніку 2/4»), не абстракція («Прогрес»)
- [ ] Новачок не мусить відкривати Discord, щоб зрозуміти старт

### Глухі кути

- [ ] Немає дверей / завалів / ліфтів, що виглядають інтерактивними, але нічого не роблять без feedback
- [ ] Немає зон, з яких не вийти без смерті / ресета
- [ ] Немає квесту, що вимагає айтем, якого ще не існує в лут-пулі поверху

### Spammy HUD

- [ ] Одночасно на екрані ≤ 1 primary objective + необхідні survival bars
- [ ] Поп-апи не стікаються стопкою; важливі не зникають за 0.5 с
- [ ] Немає постійного миготіння лічильників / токенів / XP
- [ ] Mobile safe area: HUD не накриває attack / jump / camera

### Unfair respawns

- [ ] Респаун не кидає в щільну пачку зомбі без i-frames / escape
- [ ] Респаун не на зачищеному поверсі з новою хвилею (див. §2.4)
- [ ] Після смерті тіммейт може знайти тіло / маркер і продовжити раун
- [ ] Death loop (смерть → респаун → миттєва смерть) відсутній на старті

### Token inflation

- [ ] Немає AFK / door farm / respawn farm токенів
- [ ] Нагороди за перші 5 хв відчуваються заслуженими, не «безкоштовний джекпот»
- [ ] Shop не виглядає сміттєвим через занадто дешеві топ-айтеми
- [ ] Після зниження видачі: гравці все ще можуть купити early upgrade за розумний час (не paywall відчуття)

### Fun gate (перша сесія)

- [ ] «Хочу ще один забіг» > «закриваю від злості» у більшості тестових прогонів
- [ ] Хоча б один момент «о, спрацювало / круто» у перші 5 хв (лут, сейв тіммейта, зачистка)
- [ ] Немає багу, що змушує рестартити place щоб продовжити

## 5. Ruthless adversarial — ламай сесію навмисно

Не «щасливий шлях». Роби те, що робить злий / розгублений гравець. Кожен FAIL → gap-report.

### Minute-1 quit triggers (стоп-тест)

- [ ] Спавн на даху з закритими очима 45s: чи з’являється рівно один soft ping на термінал (не стіна тексту)?
- [ ] Ігноруй термінал, одразу вниз сходами: гра все ще вчить, чи ти в «тиші без цілі»?
- [ ] Спробуй зібрати електроніку за завалом **до** лому: повідомлення зрозуміле («спочатку завал»), чи бреше як універсальний блок?
- [ ] Спробуй будь-який жовтий/amber prompt у радіусі 8 studs від завалу: чи не ловиш `Прохід завалено` на валідному scrap?
- [ ] Зачисти поверх 1 → стій 60s+: зомбі НЕ повинні повернутись (якщо повернулись — FAIL, quit fuel)
- [ ] Downed без бандажа в інвентарі команди: чи є шлях (chest/craft/drop), чи softlock до game over?

### Squad grief / co-op holes (2 клієнти)

- [ ] A чистить завал → B бачить відкритий прохід **і** може пройти (не ghost-only для A)
- [ ] A лутає scrap node → B все ще може лутати свій (або правило пояснене; зараз per-player nodes — задокументуй feel)
- [ ] A кладе хіл у «скриню» → B **не** бачить → FAIL для team-chest acceptance
- [ ] A дропає med/bandage біля downed B → B/rescue path працює (якщо drop ще немає — gap blocker)
- [ ] A hoard-ить весь crowbar/loot: чи B може прогресувати, чи один toxic teammate = run dead?
- [ ] Death backpack: тіммейт **не** може вкрасти (зараз personal) — OK для anti-grief, але тоді drop повинен існувати окремо

### Empty floor / dead air

- [ ] Пройди поверх після clear: є рішення (лут / shortcut / elevator), не «сірий коридор нічого»
- [ ] Немає поверху, де 60s+ без loot glow, threat, або gate
- [ ] Elevator/call наступного кроку очевидний після clear **або** quota (не «обидва обов’язкові» early)

### Economy / heal drought

- [ ] 15 хв ран: порахуй tokens (якщо системи ще немає — записати «missing system»)
- [ ] Витрать усі bandage/medkit: чи крафт на даху рятує без RNG-only floor drop?
- [ ] Bandage recipe discoverable без Discord (workbench UI читабельний)
- [ ] Немає AFK token/loot farm на даху / door loop

### Cross-plat hit anim (жорстко)

- [ ] Mobile attacker + PC spectator: swing видно кожні 5 ударів підряд
- [ ] Tablet landscape/portrait: те саме
- [ ] Console: baseline OK
- [ ] Якщо anim тільки SFX без руху рук — FAIL (looks like lag-cheat / broken)
