# Skyline Zero: специфікація HUD і лобі (v1)

Макети: https://claude.ai/artifact/P6SVVT6aN57TjGPZMp3duU (7 артбордів). Стан: **погоджено користувачем 2026-10-17**.
Ця специфікація замінює поточні смуги здоров'я/ситості (`HUDController.luau`), розкладку хотбара на телефоні
(`InventoryController.luau`) і масштаб `UIKit.luau:142`. Предмети, іконки та бурштинова рамка «в руці» з b15 лишаються.

## 1. Базові правила

| Правило | Значення |
|---|---|
| Основний HUD | `ScreenGui.ScreenInsets = Enum.ScreenInsets.CoreUISafeInsets`, `IgnoreGuiInset = false` |
| Повноекранні шари (впав, меню, віньєтки) | `ScreenInsets = None`, `IgnoreGuiInset = true` |
| Верхній ряд | Усе, що вгорі, ставиться відносно `GuiService.TopbarInset` (Rect), ніколи не під кнопки Roblox зліва вгорі |
| Масштаб | **Прибрати зменшення 0.65–0.8 на телефоні.** `UIScale.Scale = clamp(viewport.Y / 1080, 0.9, 1.25)` лише на ПК/консолі. На тачі `Scale = 1` і окрема розкладка (розділ 4) |
| Тип пристрою | `touch = UserInputService.TouchEnabled and not KeyboardEnabled`; `gamepad = останній ввід Gamepad*` (`LastInputTypeChanged`), розкладку перемикати на льоту |
| Тексти | Тільки через `Locale` (uk/ru/en). Усі нові рядки нижче потрібно додати в усі 3 мови |

### Шрифти (`Theme.Fonts`)

- Заголовки й числа: `Font.new("rbxasset://fonts/families/Oswald.json", Enum.FontWeight.Bold)` (SemiBold для дрібних).

- Перевірити кирилицю обох у грі на телефоні. Якщо Oswald не показує «ї/є/і», замінити числа на `BuilderSans` Bold.

## 3. Здоров'я і ситість (головне)

### Будова (`VitalsPanel`)
```
VitalsPanel (Frame, Panel, UICorner 12, UIPadding 14/16, UIListLayout Vertical gap 10)
├─ HealthRow (UIListLayout Horizontal gap 12, VerticalAlignment Center)
│  ├─ Icon (ImageLabel 26×26, хрест, Cream)
│  ├─ Segments (Frame, UIListLayout Horizontal gap 3)
│  │  └─ Seg ×10 (27×18, фон Cream прозорість 0.84, UICorner 2, ClipsDescendants)
│  │     ├─ Chip (Frame, Amber, Size (chip,0,1,0))
│  │     └─ Fill (Frame, Cream, Size (fill,0,1,0))
│  └─ Value (TextLabel, Oswald Bold 30, мін. ширина 48)
└─ HungerRow (gap 12)
   ├─ Icon (26×26, хліб, Hunger)
   ├─ Bar (300×10, UICorner 5) └─ Fill (Hunger)
   ├─ Label «Ситість» (15, CreamDim)  [лише ПК]
   └─ Badge (прихований; текст 14 Bold, фон за станом, UICorner 5, padding 3/8)
```
Сегмент `i` (0..9): `fill = clamp((hp - i*10)/10, 0, 1)`. Число завжди ціле `math.ceil(hp)`.

### Стани (макет «Здоров'я і ситість: усі стани»)

| Стан | Умова | Що видно |
|---|---|---|
| Норма | hp > 30, ситість > 25% | все спокійно |
| Удар | hp зменшився | `Chip` стоїть на старому значенні, через 0.4 с Tween до нового за 0.3 с (Quad Out). Панель трясеться ±2 px 0.15 с |
| Мало здоров'я | hp ≤ 30 | `Fill` і іконка `Danger`, пульс прозорості 0→0.35→0 за 1 с у циклі, бейдж «МАЛО ЗДОРОВ'Я», червона віньєтка по краях (ImageLabel на повний екран, прозорість 0.55), тихе серцебиття |
| Лікування | аптечка/їжа | `Chip` кольору `Heal` одразу до нового значення, `Fill` доростає за 0.5 с |
| Ситість мала | < 25% | смуга й іконка `Amber`, легке блимання раз на 3 с, один раз тост «Поїж щось» |
| Голод | ситість 0 і минув `HungerGraceSeconds` | іконка й смуга `Danger`, бейдж «ГОЛОД −1 HP/с» |
| Токсин | у токсичній зоні | бейдж `Toxic` «ТОКСИН · фільтр N с» (або без таймера), бірюзова віньєтка, **не червона** |
| Впав | downed | `Value` = 0, бейдж «ВПАВ», панель `rgba(90,22,18)` прозорість 0.15; плюс повноекранний шар (розділ 7) |

Бейджі ставляться в `HungerRow` праворуч; одночасно максимум 2 (пріоритет: Впав > Голод > Токсин > Мало здоров'я).

### Розташування
- **ПК/геймпад:** `AnchorPoint (0,1)`, `Position UDim2.new(0, 24, 1, -24)`. Зліва внизу, як у TLOU.
- **Телефон:** у верхньому ряду, праворуч від кнопок Roblox:
  `AnchorPoint (0,0)`, `Position = UDim2.fromOffset(TopbarInset.Min.X + 12, 6)`.
  Розміри телефона: іконки 18, сегмент 14×12 (gap 2), ситість 158×8, padding 7/10, gap рядків 6, без підпису «Ситість».

## 4. Телефон (844×390, макет «Телефон: HUD у вежі»)

Зони пальців: лівий палець, тобто ходьба (стандартний DynamicThumbstick), займає низ ліворуч приблизно до 26% ширини.
Правий палець, тобто дії, внизу праворуч. Тап по порожньому екрану = удар/використати (як у b14).

| Елемент | AnchorPoint | Position | Size | Примітка |
|---|---|---|---|---|
| Vitals | (0,0) | `TopbarInset.Min.X + 12, 6` | авто | див. розділ 3 |
| Ціль | (0.5,0) | (0.5,0, 0, 66) | авто, padding 6/12 | 16 + 18 Oswald для «3/8» Amber |
| Тости | (0.5,0) | (0.5,0, 0, 104) | авто | 16, максимум 2 рядки, 2.5 с |
| Напарники | (1,0) | (1,-56, 0, 8) | кружки 36 | смужка здоров'я 4 px під кружком; лежачий = червоний кружок «!» |
| Меню ☰ | (1,0) | (1,-8, 0, 6) | 40×40 | відкриває меню (розділ 6) |
| Хотбар | (0.5,1) | (0.5,0, 1,-10) | 6 слотів 54×54, gap 6, + кнопка сумки 44×54 | ліва межа ≥ 26% ширини; якщо екран < 760, 5 слотів |
| Мішечок + вага | (0.5,1) | над хотбаром, gap 6 | плашки висотою 28 | лише число 17 Oswald і іконка 12, ресурс з 0 = прозорість 0.5 |
| Назва в руці | над мішечком над вибраним слотом | | 15 Bold, Amber рамка | 1.5 с після вибору, потім fade |
| Кнопка дії | (1,1) | (1,-111, 1,-42) | 64×64 коло, обвідка Amber 3 | **лише коли є ProximityPrompt поруч**; над нею підпис дії 14 Bold; утримання = кільце Amber навколо |
| Ліхтарик | (1,1) | (1,-36, 1,-110) | 48×48 коло | над стрибком |

**Геймпад** (макет «Геймпад»): ліворуч і праворуч від хотбара плашки `LB` / `RB` (50×34); справа внизу панель підказок
`RT удар / використати`, `Y ліхтарик`, `D↑ аптечка`, `D↓ їжа`. Гліфи брати через
`UserInputService:GetImageForKeyCode(KeyCode)`, щоб на PlayStation були свої значки. Панель підказок зникає через 60 с гри
і повертається, коли гравець відкриває меню. У підказці дії на геймпаді кружок кнопки `X` (або що повертає GetImageForKeyCode).

## 6. Меню і вихід у лобі (макет «Телефон: меню і вихід у лобі»)

На HUD **немає** кнопки «В лобі». Вона лише в меню ☰:
1. Меню (панель зліва, 250 шир.): «Продовжити» (основна кремова), «Як грати», «Налаштування» (поки можна сховати), розділювач, «Покинути забіг» (контур Danger, текст DangerText).
2. «Покинути забіг» відкриває діалог 420 шир.: заголовок «Покинути забіг?» 26 Oswald, текст «Ти повернешся в лобі. Усе зібране в цьому забігу пропаде. Напарники продовжать без тебе.»
3. Кнопки: «Залишитися» (основна, широка, за замовчуванням вибрана на геймпаді) і «Вийти» з **утриманням 1.5 с** (заливка зліва направо `#A3352A`; відпустив раніше = скидається). Тільки після утримання клієнт шле запит.
4. Під час утримання вібрація на геймпаді/телефоні (`HapticService`, якщо є).

Код треду вже прибирає/захищає цю кнопку, тому цей розділ лише задає вигляд.

## 7. Ти впав (макет «Телефон: ти впав»)

- Повноекранний шар: `ColorCorrectionEffect` Saturation −0.6, Contrast 0.1; червона віньєтка по краях.
- По центру зверху на 92 px: «ТИ ВПАВ» 40 Oswald Bold (ПК 56), під ним 17: «Напарник може підняти тебе бинтом».
- Список напарників (340 шир., рядки 16/15): ім'я, відстань у метрах, «має бинт» (Hunger-колір) або «без бинта» (CreamDim). Оновлення раз на 0.5 с.
- Справа внизу місце під майбутню Robux-кнопку «Піднятися самому» (зараз приховано або «скоро»).
- Хотбар і кнопки дій приховані. Vitals лишаються з бейджем «ВПАВ».
- Той, хто піднімає: кільце утримання Amber у кнопці дії/підказці, підпис «Піднімаєш…».

## 8. Лобі (макет «Телефон: лобі, ти в ліфті»)

- Справа вгорі (від `1,-8`): жетони (кружок Amber + число 19 Oswald + «жетонів» 13), «Рекорди» (відкриває табло крупно), «?» (Як грати). Висота 40.
- Картка ліфта, коли гравець у зоні ліфта: `AnchorPoint (0.5,1)`, `Position (0.5,0, 1,-10)`, ширина 420 (ПК 480):
  назва «Ліфт на 4 гравців» 22 Oswald, таймер 26 Oswald AmberText, смуга прогресу 6 px Amber, кружки гравців 30 (порожні пунктиром),
  кнопка «Вийти з ліфта» 44 вис., підпис «Ліфт повний: відлік у 3 рази швидший» 13 Muted.
- Тег білда: справа внизу 12, напівпрозорий.
- Над дверима ліфта у світі (BillboardGui): «ЛІФТ НА 4 · 2/4» 20 Oswald AmberText.

## 9. Підказка шляху вниз

Разом зі світлом у проходах (робить тред коду): коли ціль «спустись на N поверх», над входом на сходи показувати маркер
(BillboardGui, `AlwaysOnTop`, макс. дистанція 60 studs): стрілка вниз Amber 34 + плашка «Сходи · 14 м» 16 Bold. На краю екрана, якщо сходи поза кадром,
стрілка-вказівник по периметру (вже є `ObjectiveMarker`, використати його стиль).

## 11. Як перевірити

1. Телефон 720×360 (найменший Android) і 844×390: нічого не налазить на джойстик, стрибок і кнопки Roblox; найменший текст ≥ 13 px.
2. iPhone з вирізом: нічого не під вирізом (CoreUISafeInsets).
3. Планшет 1024×768: розкладка телефона, але хотбар 8 слотів.
4. ПК 1366×768 і 2560×1440: UIScale в межах 0.9–1.25.
5. Геймпад: переключення миша → геймпад міняє підказки без перезаходу.
6. Усі стани здоров'я/ситості з таблиці розділу 3 видно хоч раз.
