# Черга задач для локального агента Cursor

Виконуй задачі по черзі, по одній. Після кожної коротко опиши причину, змінені файли і як перевірити. Нічого не публікуй (місця, збірки), доки власник не дозволить.

## 1. Баг: на планшеті не видно анімації удару — DONE (local, Unreleased)
- Що не так: на планшеті при тапі для атаки не видно анімації удару. На телефоні та на PlayStation вона видна.
- Виправлення: Touch з `processed=true` на world більше не ігнорується (лише GuiButton); ширший tap slop;
  retry анімації; `UIKit.IsTouch` через `PreferredInput.Touch`. Перевірити на планшеті перед publish.

## 2. Баг: мерехтіння при вході в прохід
- Що не так: коли гравець заходить у прохід, світло мерехтить.
- Що зробити: або виправити мерехтіння, або прибрати його зовсім і залишити просто тьмяний ліхтарик. Обрати найпростіший надійний варіант. Після виправлення мерехтіння бути не повинно.

## 3. Задача: нова зброя замінює стару того ж типу — DONE (local, Unreleased)
- Що не так: у інвентарі можуть бути два мечі чи дві дубини одночасно.
- Виправлення: серверний `InventoryService` — краща melee (rank) знімає слабшу; слабша не додається поверх сильнішої; Equipped зберігається / переходить на нову.

## 4. Баг: розмитий фон під підсвіченим предметом
- Що не так: після кліку на новий предмет предмети підсвічуються жовтим або іншим кольором, але фон надто розмитий, тексту не видно.
- Що зробити: зробити фон чіткішим (менше розмиття або щільніша підкладка), щоб текст читався на телефоні й планшеті.

## 5. Баг: текст вилазить за чорну плашку
- Що не так: деякі тексти, наприклад «ціль», не вміщаються в чорну плашку фону і виходять за її межі.
- Що зробити: підігнати розмір тексту або плашки (автопідбір розміру чи розтягування плашки під текст), щоб текст повністю вміщався. Перевірити на телефоні й планшеті та для всіх мов (uk, ru, en).

## 6. Баг: забагато сундуків і спільний лут у команді — DONE (local, Unreleased / Phase A)
- Що не так: сундуків у грі забагато, їх легко знайти.
- Виправлення: менше ящиків на поверх (1 / 1 / 1–2 / 1+Diamond); opened state спільний для партії на сервері.
