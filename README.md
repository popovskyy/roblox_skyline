# Skyline Zero

Roblox-гра про виживання на даху хмарочоса. Сірий прототип (тільки Parts), код синхронізується в Studio через Rojo.

## Запуск у Roblox Studio

1. У терміналі в цій папці запусти сервер Rojo:
   ```
   rojo serve
   ```
2. У Studio відкрий будь-який place (можна порожній Baseplate).
3. Встанови плагін Rojo, якщо його ще немає: `rojo plugin install` (потім перезапусти Studio).
4. На вкладці **Plugins** натисни **Rojo → Connect** (адреса `localhost:34872`).
5. Натисни **Play**. Карта будується сама при старті сервера (`Workspace.GeneratedWorld`).

Щоб перевіряти збереження, увімкни в Studio: **Game Settings → Security → Enable Studio Access to API Services** (place має бути опублікований). Без цього гра працює, але прогрес не зберігається, і в Output буде попередження.

Для швидкого проходження до фіналу постав `TestPrices = true` у `src/ReplicatedStorage/Shared/GameConfig.luau` (усі поліпшення коштуватимуть по 1 предмету). Перед публікацією поверни `false`.

## Керування

- `E` або кнопка «Взаємодія» на телефоні: збирати, будувати, відкривати.
- `I`: інвентар (аптечка, їжа).
- `F`: ліхтарик.

## Структура

```
src/ReplicatedStorage/Shared     конфіг, предмети, поліпшення, типи, назви RemoteEvent
src/ServerScriptService          ServerMain, WorldBuilder, Services/*
src/StarterPlayer/...Scripts     ClientMain і Controllers/* (тільки UI та локальний візуал)
src/StarterPlayer/...CharacterScripts/Health  вимикає стандартну регенерацію здоров'я
```

Увесь баланс у `GameConfig.luau`, `ItemDefinitions.luau`, `UpgradeDefinitions.luau`.
Донат вимкнено для MVP: усе, що його стосується, у `MonetizationConfig.luau` і `MonetizationService.luau`.

## Перевірка коду

```
stylua src
selene src
rojo build -o SkylineZero.rbxlx
```

## Ручний чекліст у Studio

1. Спавн на даху, термінал показує записку і «0 / 3».
2. Спуск сходами до 4 поверху і назад; двері на 4 поверх закриті без генератора.
3. Один вузол збирається один раз; після повернення на дах вузли знову повні (крім ліхтарика).
4. Взаємодія далі ніж 12 studs відхиляється; повний рюкзак не бере нові ресурси.
5. Перший завал на 1 поверсі розбирається без інструмента і дає лом.
6. Сховище: перенесення туди й назад не змінює загальну кількість.
7. Поліпшення без ресурсів не купується; повторна покупка неможлива.
8. Токсична зона на 3 поверсі б'є після 2 с; фільтр зменшує шкоду.
9. Аптечка при повному здоров'ї не витрачається.
10. Смерть: рюкзак лишається на місці смерті, його можна забрати один раз.
11. Міст без генератора не будується; після мосту перехід на сусідню вежу показує фінал.
12. Вихід і повторний вхід зберігає поліпшення, сховище і ліхтарик (з увімкненим API).
13. Два клієнти (Test → Clients and Servers): дані гравців не змішуються.
